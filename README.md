# Duplicate questions (qbank_duplicates)

Adds a **Duplicates** page to the Moodle question bank. It groups questions of the same type in the current category whose text is the same once formatting, capitals, spaces and punctuation are ignored, so you can clean up after imports, backups restored twice, or copies made by several teachers.

- Open the question bank, then choose **Duplicates** from the question bank menu.
- Each group shows the shared text, and every copy with its name, when it was last changed and a link to edit it.
- Only the latest version of each question counts, and hidden questions are ignored.
- Nothing is deleted or merged for you: you decide which copies to keep.

Needs moodle/question:viewall in the bank's context. Moodle 4.5 (course question banks) to 5.3 (question bank activities).
